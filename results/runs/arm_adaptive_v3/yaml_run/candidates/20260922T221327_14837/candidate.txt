name: mj_gated_confidence_rank
doc: >
  Introduces a new unified ranking logic, `gated_confidence_etr`, to address the
  conflict between `kept_dead` and `wrong_bypass` errors. This logic acts as a gate:
  if confidence in a line's predicted reuse is below a threshold, it is assigned the
  maximum ETR, marking it for immediate eviction or bypass. If confidence is high,
  its ETR is based on its predicted reuse distance (RDP). This single, consistent
  rank is applied to both eviction and bypass decisions, aiming for a more accurate
  policy that is aggressive with untrusted predictions while being protective of
  trusted ones.

state:
  - name: etr
    scope: per_line
    kind: signed
    width: 5                  # holds -11..11
    init: 0
  - name: etr_clock
    scope: per_set
    kind: counter
    width: 4
    init: 8                   # GRANULARITY: the first access to a set ages it
  - name: set_clock
    scope: per_set
    kind: counter
    width: 8                  # TIMESTAMP_BITS
    init: ZERO

victim:
  key: etr
  extremum: max_magnitude
  tie_break: prefer_negative
  on_search: none
  bypass_when:
    - gated_etr_gt_threshold:
        rdp_table: rdp
        conf_table: rdp_conf
        index: pc_sig
        div: 8
        max_etr: 11
        conf_threshold: 2
        threshold: 10
    - gated_etr_exceeds_victim:
        rdp_table: rdp
        conf_table: rdp_conf
        index: pc_sig
        div: 8
        max_etr: 11
        conf_threshold: 2

signatures:
  - name: pc_sig
    source: ip
    fold: [hit, prefetch]
    hash: crc3
    low_bits: 11

tables:
  - name: rdp
    scope: global
    kind: saturating
    entries: 2048
    width: 7
    max: 95                   # INF_RD
    unset: true
  - name: rdp_conf
    scope: global
    kind: saturating
    entries: 2048
    width: 2
    init: ZERO

samplers:
  - name: sampled_cache
    scope: global
    sets: {mirror: 32}
    extra_index_bits: 4       # 16 sampler sets per sampled set
    ways: 5
    tag_bits: 10
    fields:
      - {name: signature, kind: counter, width: 11, init: ZERO}
      - {name: timestamp, kind: counter, width: 8, init: ZERO}
    age: {clock: set_clock, stamp: timestamp}
    victim: {key: age, extremum: max, tie_break: first, prefer_free: true}
    on_match:
      - when: {counter: {counter: age, cmp: gt, threshold: 95}}
        stop: true
      - when: {type_in: [PREFETCH]}
        train_sampler_match: {rdp_table: rdp, conf_table: rdp_conf, index: signature, sample: age, scale: 2, min_diff: 16, conf_thresh: 48}
        free: true
        stop: true
      - train_sampler_match: {rdp_table: rdp, conf_table: rdp_conf, index: signature, sample: age, scale: 1, min_diff: 16, conf_thresh: 48}
        free: true
    sweep:
      - when: {counter: {counter: age, cmp: gt, threshold: 95}}
        train: {table: rdp, index: signature, op: increment}
      - when: {counter: {counter: age, cmp: gt, threshold: 95}}
        train: {table: rdp_conf, index: signature, op: decrement}
        free: true
    on_replace:
      - train: {table: rdp, index: signature, op: increment}
      - train: {table: rdp_conf, index: signature, op: decrement}
    install: {signature: {signature: pc_sig}, timestamp: {read: set_clock}}
    after:
      - set: {set_clock: {add: 1}}

procedures:
  access:
    - sample: sampled_cache
    - when: {counter: {counter: etr_clock, cmp: eq, threshold: 8}}
      each_way:
        except_touched: true
        when: {counter: {counter: etr, cmp: lt, threshold: 11, abs: true}}
        set: {etr: {add: -1}}
    - when: {counter: {counter: etr_clock, cmp: eq, threshold: 8}}
      set: {etr_clock: {const: 0}}
    - set: {etr_clock: {add: 1}}
    - set:
        etr:
          gated_confidence_etr:
            rdp_table: rdp
            conf_table: rdp_conf
            index: pc_sig
            div: 8
            max_etr: 11
            conf_threshold: 2

on_hit:
  - when: {type_in: [WRITE]}
    stop: true
  - run: access

on_fill:
  - when: {type_in: [WRITE]}
    set: {etr: {const: -11}}
    stop: true
  - run: access

- name: train_sampler_match
  place: step
  params:
    conf_table: table
    conf_thresh:
      int: [0, 127]
    index: signature
    min_diff:
      int: [0, 127]
    rdp_table: table
    sample: state
    scale:
      int: [1, 2]
  means: >
    Performs training for a sampler match based on the reuse distance 'sample' (age).
    First, it trains the rdp_table using the 'toward' operation. The target value is min(sample * scale, rdp_table.max). The entry moves one step toward the target if the difference from the target is at least min_diff.
    Second, if the 'sample' value is less than conf_thresh, it increments the conf_table entry at the same index.
- name: gated_confidence_etr
  place: value
  params:
    rdp_table: table
    conf_table: table
    index: signature
    div: {int: [1, 128]}
    max_etr: {int: [0, 15]}
    conf_threshold: {int: [0, 3]}
  means: >
    Reads 'conf_val' from conf_table[index] (an absent entry is treated as 0).
    If 'conf_val' is less than conf_threshold, the function returns max_etr.
    Otherwise, it reads 'rdp_val' from rdp_table[index] (an absent entry is treated as 0).
    It then returns min(max_etr, rdp_val / div), using integer division.
- name: gated_etr_gt_threshold
  place: condition
  params:
    rdp_table: table
    conf_table: table
    index: signature
    div: {int: [1, 128]}
    max_etr: {int: [0, 15]}
    conf_threshold: {int: [0, 3]}
    threshold: {int: [0, 15]}
  means: >
    Calculates an estimated time to reuse (ETR) value using the 'gated_confidence_etr' logic:
    Reads 'conf_val' from conf_table[index] (absent is 0). If 'conf_val' < conf_threshold,
    ETR is max_etr. Otherwise, reads 'rdp_val' from rdp_table[index] (absent is 0) and
    ETR is min(max_etr, rdp_val / div).
    Returns true if the calculated ETR is greater than the given threshold.
- name: gated_etr_exceeds_victim
  place: condition
  params:
    rdp_table: table
    conf_table: table
    index: signature
    div: {int: [1, 128]}
    max_etr: {int: [0, 15]}
    conf_threshold: {int: [0, 3]}
  means: >
    Calculates an estimated time to reuse (ETR) value using the 'gated_confidence_etr' logic:
    Reads 'conf_val' from conf_table[index] (absent is 0). If 'conf_val' < conf_threshold,
    ETR is max_etr. Otherwise, reads 'rdp_val' from rdp_table[index] (absent is 0) and
    ETR is min(max_etr, rdp_val / div).
    Returns true if the calculated ETR is greater than the absolute value of the victim way's key.
