===== STRUCTURE_DESCRIPTION =====
name: mockingjay_wrong_bypass_feedback
doc: >
  Mockingjay with wrong_bypass feedback: Added a new table to track PC signatures
  that were wrongly bypassed. A new flag in the sampler records if an entry was
  bypassed in the main cache. If a bypassed entry later hits in the sampler, the
  wrong_bypass_predictor is decremented for its signature. If a bypassed entry
  is replaced in the sampler without a hit, the predictor is incremented. The
  bypass decision now consults this predictor to avoid re-bypassing frequently
  wrongly bypassed lines.

state:
  - name: etr
    scope: per_line
    kind: signed
    width: 5                  # holds -11..11
    init: 0
  - name: etr_clock
    scope: per_set
    kind: counter
    width: 4
    init: 8                   # GRANULARITY: the first access to a set ages it
  - name: set_clock
    scope: per_set
    kind: counter
    width: 8                  # TIMESTAMP_BITS; wraps by design
    init: ZERO

victim:
  key: etr
  extremum: max_magnitude
  tie_break: prefer_negative
  on_search: none
  bypass_when:                # the incoming line is predicted to be reused after every resident
    - {table: {table: rdp, index: pc_sig, cmp: gt, threshold: 73}}
    - {table_exceeds_victim: {table: rdp, index: pc_sig, div: 8}}
    # New condition: do not bypass if the wrong_bypass_predictor indicates this signature was wrongly bypassed (value < 2)
    - {table: {table: wrong_bypass_predictor, index: pc_sig, cmp: lt, threshold: 2}}

signatures:
  - name: pc_sig
    source: ip
    fold: [hit, prefetch]
    hash: crc3
    low_bits: 11

tables:
  - name: rdp
    scope: global
    kind: saturating
    entries: 2048
    width: 7
    max: 95                   # INF_RD
    unset: true
  - name: wrong_bypass_predictor # New table to track wrong bypasses
    scope: global
    kind: saturating
    entries: 2048             # Same size as RDP
    width: 3                  # e.g., 0-7. MID for width 3 is 3.
    init: MID                 # Start neutral (value 3)
    max: 7
    unset: false

samplers:
  - name: sampled_cache
    scope: global
    sets: {mirror: 32}
    extra_index_bits: 4       # 16 sampler sets per sampled set
    ways: 5
    tag_bits: 10
    fields:
      - {name: signature, kind: counter, width: 11, init: ZERO}
      - {name: timestamp, kind: counter, width: 8, init: ZERO}
      - {name: was_bypassed, kind: flag, width: 1, init: ZERO} # New flag to mark bypassed entries
    age: {clock: set_clock, stamp: timestamp}
    victim: {key: age, extremum: max, tie_break: first, prefer_free: true}
    on_match:
      - when: {counter: {counter: age, cmp: gt, threshold: 95}}
        stop: true            # too old to be a reuse distance; the sweep detrains it
      - when: {counter: {counter: was_bypassed, cmp: eq, threshold: 1}} # If this entry was previously bypassed and now hit
        train: {table: wrong_bypass_predictor, index: signature, op: decrement} # Decrement WBP (less likely to bypass this signature)
        set: {was_bypassed: {const: 0}} # Reset the flag
        stop: true # This was a wrong bypass, don't train RDP with it
      - when: {type_in: [PREFETCH]}
        train: {table: rdp, index: signature, op: toward, sample: age, scale: 2, min_diff: 16}
        free: true
        stop: true
      - train: {table: rdp, index: signature, op: toward, sample: age, min_diff: 16}
        free: true
    sweep:
      - when: {counter: {counter: age, cmp: gt, threshold: 95}}
        train: {table: rdp, index: signature, op: increment}
        free: true
    on_replace:
      - when: {counter: {counter: was_bypassed, cmp: eq, threshold: 1}} # If a bypassed entry is evicted from sampler without a hit
        train: {table: wrong_bypass_predictor, index: signature, op: increment} # Increment WBP (more likely to bypass this signature)
        set: {was_bypassed: {const: 0}} # Reset the flag
      - train: {table: rdp, index: signature, op: increment}
    install: {signature: {signature: pc_sig}, timestamp: {read: set_clock}, was_bypassed: {const: 0}} # Default to not bypassed
    after:
      - set: {set_clock: {add: 1}}

procedures:
  access:                     # mockingjay.cc access(): the update body shared by hits and non-bypassed fills
    - sample: sampled_cache   # Sample the cache for RDP training
    - when: {counter: {counter: etr_clock, cmp: eq, threshold: 8}}
      each_way:
        except_touched: true
        when: {counter: {counter: etr, cmp: lt, threshold: 11, abs: true}}
        set: {etr: {add: -1}}
    - when: {counter: {counter: etr_clock, cmp: eq, threshold: 8}}
      set: {etr_clock: {const: 0}}
    - set: {etr_clock: {add: 1}}
    - when: {table: {table: rdp, index: pc_sig, cmp: absent}}
      set: {etr: {const: 0}}
      stop: true
    - when: {table: {table: rdp, index: pc_sig, cmp: gt, threshold: 73}}
      set: {etr: {const: 11}}
      stop: true
    - set: {etr: {table: rdp, index: pc_sig, div: 8}}

on_hit:
  - when: {type_in: [WRITE]}
    stop: true
  - run: access

on_fill:
  - when: {type_in: [WRITE]}
    set: {etr: {const: -11}}
    stop: true
  - when: {way: NUM_WAY} # If the fill was bypassed (no line installed in main cache)
    mark_sampler_as_bypassed: {sampler: sampled_cache, bypassed_flag_field: was_bypassed, sampler_signature_field: signature, sampler_timestamp_field: timestamp, current_signature: pc_sig, current_timestamp_value: {read: set_clock}}
    stop: true # No ETR is set as no line is installed in the main cache
  - run: access # For non-bypassed fills, which will install a line and set its ETR
===== NEW_WORDS =====

- name: mark_sampler_as_bypassed
  place: step
  params:
    sampler: sampler
    bypassed_flag_field: {sampler_field: flag}
    sampler_signature_field: {sampler_field: counter}
    sampler_timestamp_field: {sampler_field: counter}
    current_signature: signature
    current_timestamp_value: {read: set_clock}
  means: >
    This step is intended to be called in the main cache's on_fill event only when
    the fill was bypassed (way == NUM_WAY). If the current main cache set is sampled
    by the named `sampler`, the sampler is updated for the current line address.
    If an existing sampler entry matches the line's tag: its `bypassed_flag_field`
    is set to true, its `sampler_signature_field` is updated with `current_signature`,
    and its `sampler_timestamp_field` is updated with `current_timestamp_value`.
    If no entry matches, a new entry is installed: its tag is set to the current
    line's tag, its `bypassed_flag_field` to true, its `sampler_signature_field`
    to `current_signature`, and its `sampler_timestamp_field` to `current_timestamp_value`.
    All other fields of the new entry are set to their init values. The sampler's
    on_match, sweep, on_replace, and after rules are NOT run for this specific operation.
